## 📋 Overview

Pawthentic is a responsive website dedicated to providing honest, thorough, and authentic pet product reviews. Our mission is to help pet parents make informed decisions for their furry companions by offering unbiased reviews and helpful advice for all pet needs.

![[Pawthentic Website Preview](https://amungabrenda.github.io/pawthentic/)]
---

## ✨ Features

- 🏠 **Responsive Home Page**: Welcoming interface with featured articles and category navigation
- 📝 **Blog Section**: Detailed product reviews with ratings and price comparisons
- 🐕 **Category Filtering**: Browse products by pet type (dogs, cats, small pets, aquatic)
- 📱 **Mobile-Friendly Design**: Fully responsive layout that works on devices of all sizes
- 📧 **Newsletter Subscription**: Stay updated with the latest pet product reviews
- 🔄 **Social Media Integration**: Connect with Pawthentic across multiple platforms

## 🚀 Getting Started

### Prerequisites

- Any modern web browser
- Basic understanding of HTML/CSS (for development)

### Installation

1. Clone the repository
```bash
git clone https://github.com/AmungaBrenda/pawthentic.git
```

2. Navigate to the project directory
```bash
cd pawthentic
```

3. Open `index.html` in your browser to view the website

## 📱 Responsive Design

Pawthentic is designed to be fully responsive across:
- Desktop (1024px and above)
- Tablet (768px to 1023px)
- Mobile (up to 767px)

Media queries ensure optimal viewing experience across all device sizes.
